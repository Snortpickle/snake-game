# Неоновая Змейка 🐍

Красивая браузерная версия классической «Змейки» с неоновым оформлением. Игра написана на чистых HTML, CSS и JavaScript: сборка и установка зависимостей не нужны.

## Возможности

- управление стрелками, `WASD` и русской раскладкой `ЦФЫВ`;
- сенсорные кнопки для телефона и планшета;
- пауза по клавише `Пробел`;
- сохранение лучшего результата в браузере;
- звуковые эффекты, которые можно отключить;
- три скорости игры: «Спокойно», «Обычно» и «Быстро»;
- адаптивный интерфейс для больших и маленьких экранов.

## Как запустить

### Самый простой способ

Откройте файл `index.html` двойным щелчком — игра запустится в браузере.

### Через локальный сервер (рекомендуется)

В каталоге проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере [http://localhost:8000](http://localhost:8000).

## Как играть

1. Нажмите кнопку **«Играть»** или любую клавишу направления.
2. Управляйте змейкой стрелками, клавишами `WASD` или `ЦФЫВ`.
3. Собирайте светящиеся кристаллы — каждый приносит 10 очков.
4. Не врезайтесь в стены и собственный хвост.
5. Нажмите `Пробел` или кнопку паузы, чтобы остановить игру.
6. Выберите удобную скорость в меню справа от игрового поля. По умолчанию включён медленный режим «Спокойно».

На мобильном устройстве используйте кнопки со стрелками под игровым полем.

## Как это работает

Поле разделено на сетку 20 × 20 клеток и отрисовывается на HTML5 Canvas. Интервал движения зависит от выбранной скорости: 190 мс, 130 мс или 85 мс. Остальные сегменты занимают предыдущие позиции головы. При подборе кристалла хвост не удаляется, поэтому змейка становится длиннее. Столкновение с границей поля или своим телом завершает раунд.

Рекорд и выбранная скорость хранятся локально с помощью `localStorage`, поэтому останутся после перезагрузки страницы в том же браузере.
